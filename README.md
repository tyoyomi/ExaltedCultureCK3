# Exalted Culture

Crusader Kings III mod. Version **0.3.0**. Supported game version `1.20.*`.

Appoint an Exalted Culturalist to accelerate innovations (fascinations), tradition adoption, cultural acceptance, and hybrid/diverge reachability. Full package requires culture head.

## 0.3.0 next-iter

- **Hybridize / diverge express lane** — decade assist + High Form Now
- **Realm culture paint** — de jure kingdom paint with one undo + acceptance cushion
- **Language diplomacy** — realm languages, court language, guest/courtier opinion (EC = realm; SS All Languages = global)
- **Binder + title-gain cheap path** — O(bound) patron lists; title-gain is self-only

Canonical working copy: `Documents/Development/CK3 Mods/ec`.

Soft-recommends Royal Court for hybridize Form Now and court language. Pair with vanilla Faster Hybrid & Divergence Cooldowns if you want age gates reduced. May conflict with culture overhaul mods that also redefine tradition cost/cooldown script values.
