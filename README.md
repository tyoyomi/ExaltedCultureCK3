# Exalted Culture

Crusader Kings III mod. Version 0.1.0. Supported game version 1.20.*.

Appoint an Exalted Culturalist to accelerate innovations (fascinations), tradition adoption, cultural acceptance, and hybrid/diverge reachability. Full package requires culture head.

Canonical working copy: `Documents/Development/CK3 Mods/ec`.

Soft-recommends Royal Court for hybridize/diverge UI. Pair with vanilla Faster Hybrid & Divergence Cooldowns if you want age gates reduced. May conflict with culture overhaul mods that also redefine tradition cost/cooldown script values.
